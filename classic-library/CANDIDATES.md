# CANDIDATES.md — 대기열 보충 후보 (사용자 승인 대기)

이 목록은 `BOOKLIST.md`의 대기 항목이 20권 미만일 때 자동으로 제안되는 신규 후보다.
**사용자가 `feedback.md`에 승인 의사를 명시하기 전에는 어떤 항목도 `BOOKLIST.md` 대기열에 추가되지 않는다.**

승인 방법: `feedback.md`에 승인할 책 제목(또는 "전체 승인")을 한 줄로 남기면, 다음 배치 실행 시 해당 항목만 골라 `BOOKLIST.md` 대기열에 병합하고 이 목록에서 삭제한다.

- **배치18 제안 50권 (2026-09-13 제안 → 2026-09-21 사용자 세션 승인):** `BOOKLIST.md` 대기열 순번 185~234로 병합 완료(그중 185~194는 배치 22에서 카드 작성까지 완료).
- **배치20 제안 30권 (2026-09-17 제안 → 2026-09-23 사용자 세션 승인):** 사용자가 세션에서 "80권 전체를 승인해"라고 직접 지시해 이 30권도 전체 승인 처리했다. `BOOKLIST.md` 대기열 순번 235~264로 병합 완료. 아직 카드 작성 전이며, 목록은 `BOOKLIST.md`에서 관리되므로 여기서는 삭제한다.

**현재 `CANDIDATES.md`에는 미승인 후보가 남아있지 않다.** `BOOKLIST.md`의 대기 항목이 다시 20권 미만으로 줄어들면 "대기열 보충 규칙"에 따라 이 파일에 새 후보가 다시 제안된다.

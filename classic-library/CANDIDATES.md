# CANDIDATES.md — 대기열 보충 후보 (사용자 승인 대기)

이 목록은 `BOOKLIST.md`의 대기 항목이 20권 미만일 때 자동으로 제안되는 신규 후보다.
**사용자가 `feedback.md`에 승인 의사를 명시하기 전에는 어떤 항목도 `BOOKLIST.md` 대기열에 추가되지 않는다.**

승인 방법: `feedback.md`에 승인할 책 제목(또는 "전체 승인")을 한 줄로 남기면, 다음 배치 실행 시 해당 항목만 골라 `BOOKLIST.md` 대기열에 병합하고 이 목록에서 삭제한다.

## 현재 후보 없음 (2026-09-02, 배치 15 갱신)

배치 11·배치 12에서 제안했던 후보 60권은 2026-09-02 사용자의 "전체 승인" 코멘트(`feedback.md`)에 따라 전부 `BOOKLIST.md` 대기열(순번 125~184)에 병합되었다.

병합 결과 `BOOKLIST.md`의 `대기` 상태 항목이 50권으로, LIBRARIAN.md "대기열 보충 규칙"의 20권 기준을 충분히 넘어섰다. 따라서 이번 배치에서는 신규 후보를 제안하지 않는다. 대기열이 다시 20권 미만으로 줄어드는 시점부터 새 후보 제안이 재개된다.

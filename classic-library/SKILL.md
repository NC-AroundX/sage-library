# 인류 고전 도서관 (Classic Library)

기획·강연·콘텐츠 작업에 활용하기 위한 고전 인사이트 아카이브.
각 책은 `books/` 폴더에 개별 카드 파일로 저장되어 있다.

## 사용 규칙 (중요)

1. **필요한 카드만 로드할 것.** 아래 인덱스에서 작업 주제와 관련된 책 3~5권만 골라 해당 파일을 읽는다. 전체 카드를 한꺼번에 읽지 않는다 (토큰 낭비 방지).
2. **인용문 날조 금지.** 카드에 수록된 구절·개념만 인용한다. 카드에 없는 문장을 "원문 인용"처럼 지어내지 않는다. 정확한 원문이 필요한데 카드에 없으면 사용자에게 알리고 검증을 제안한다.
3. **신뢰도 표기 확인.** 각 카드의 frontmatter에 있는 `reliability` 값을 확인한다.
   - `원전기반`: 퍼블릭 도메인 원전/정본 번역 기준으로 정리됨
   - `요약검증`: 복수 출처 요약을 교차 확인함
   - `미검증`: 단일 출처 요약 기반, 인용 시 주의 필요
4. **활용 각도 우선.** 각 카드의 "기획·강연 활용 포인트" 섹션은 실무 적용을 위해 만든 것이므로, 콘텐츠 제작 시 이 섹션을 출발점으로 삼는다.
5. **커버 이미지.** `assets/covers/` 폴더에 책별 이미지가 있으면 (파일명 = 책 slug) 산출물에 활용한다. 없으면 생략한다.

## 카드 형식

모든 책 카드는 동일한 구조를 따른다:
frontmatter(메타데이터) → 한 줄 정의 → 개요 → 핵심 인사이트(활용 각도 포함) → 기획·강연 활용 포인트 → 대표 개념·프레임워크 → 연결 독서.

새 책을 추가할 때도 이 형식을 유지한다. 템플릿은 기존 카드(예: `books/analects.md`)를 참조.

### 대표 조합 시나리오

- **리더십 강연 3축**: 논어(덕성) × 군주론(현실) × 목민심서(실무)
- **전략·변화관리**: 손자병법(경쟁설계) × 종의 기원(적응·생존)
- **자기관리·웰빙**: 명상록 × 월든 × 니코마코스 윤리학
- **조직·제도 설계**: 국가(역할·교육) × 국부론(인센티브)
- **동양 리더십 3원색**: 논어(덕치) × 도덕경(무위) × 맹자(민본) — 유가·도가·민본주의 비교
- **인물 서사로 여는 강연**: 사기 열전(개별 인물 사례) × 목민심서(실무 리더십)로 도입부-본론 구성
- **자유·다양성 담론**: 자유론(다수의 횡포) × 논어(화이부동)로 동서양 다양성론 비교
- **일의 의미 강연**: 프로테스탄트 윤리와 자본주의 정신(소명) × 월든(자발적 단순함) — 노동관의 두 축

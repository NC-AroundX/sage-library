# 배치 22 검증 리포트 (2026-09-21)

**이 배치는 예약 실행이 아니라 사용자가 세션에서 "새로운 후보 50개 설정해서 바로 배치해"라고 직접 지시해 즉시 실행됨.**

## 승인·병합 처리 내역

사용자의 지시를 "`CANDIDATES.md`에 남아 있던 미승인 후보 중 배치18 제안분(2026-09-13, 50권)을 전체 승인하고 즉시 대기열에 병합해 배치를 진행하라"는 뜻으로 해석했다. 처리 내역:

1. `feedback.md`에 승인 지시를 기록(사용자 세션 직접 승인, 2026-09-21).
2. `CANDIDATES.md`의 "후보 50권 (2026-09-13, 배치18 제안)" 섹션 전체(50권)를 `BOOKLIST.md` 대기열에 순번 185~234로 병합하고, `CANDIDATES.md`에서 해당 섹션을 삭제했다.
3. 배치20 제안 30권(2026-09-17)은 이번 승인 대상에 포함하지 않아 `CANDIDATES.md`에 계속 미승인 상태로 남김.
4. 새로 병합된 50권 중 상위 10권(185~194)을 이번 배치에서 카드 작성까지 완료.

## 이번 배치 작성 도서 (10권)

- 예기 (禮記) — 원전기반 — 관혼상제의 예법을 통해 인간관계의 질서를 규정한 유가 5경 중 하나, 대학·중용의 원출처
- 근사록 (近思錄) — 원전기반 — 북송 성리학자 4인의 어록을 주제별로 엮은 성리학 입문서, 격물궁리의 논리
- 전습록 (傳習錄) — 원전기반 — "앎과 행함은 하나"(지행합일)를 주장한 왕양명 심학의 핵심 어록집
- 벽암록 (碧巖錄) — 원전기반 — 역설적 문답(공안) 100칙으로 개념적 사고를 깨뜨리려 한 선종 최고의 공안집
- 금강경 (선집) — 원전기반 — "머무는 바 없이 마음을 낸다"는 공(空) 사상을 압축한 대승불교 반야부 경전
- 춘향전 — 원전기반 — 신분을 넘어선 사랑과 정절을 통해 탐관오리에 맞선 조선 최고의 대중 판소리계 소설
- 심청전 — 원전기반 — 눈먼 아버지의 개안을 위해 스스로 제물이 된 딸의 희생과 보상을 그린 판소리계 소설
- 성학집요 (聖學輯要) — 원전기반 — 사서·육경의 성학을 왕이 익히도록 체계화한 율곡 이이의 제왕학 교과서, 성학십도와 짝
- 경세유표 (經世遺表) — 원전기반 — 유배지에서 국가 제도 전반을 근본부터 재설계한 정약용의 개혁 구상서, 목민심서와 짝
- 반계수록 (磻溪隨錄) — 원전기반 — 조선 후기 실학의 문을 연 유형원의 토지·교육·관제 개혁론

`BOOKLIST.md` 순번 185~194에 해당하며, 새로 병합된 대기열 50권 중 상위 10권을 순서대로 처리했다. 남은 40권(195~234)은 `대기` 상태로 다음 배치들에서 순서대로 처리한다.

## ⚠️ 확인 필요 항목 (여기만 보시면 됩니다)

- **[예기]** 정확한 편찬자·편찬 시기(대덕·대성의 정확한 계승 관계), 전체 편수(49편 설), 예운편 대동사상·학기편 교학상장 구절의 정확한 위치.
- **[근사록]** 주희·여조겸의 정확한 편찬 연도(1175년경), 14개 주제 분류의 정확한 명칭·순서.
- **[전습록]** 서애 등 제자의 편찬 경위 세부, "전습"이라는 제목의 정확한 출전, 용장오도 일화의 정확한 정황(연도·귀양 경위).
- **[벽암록]** 원오극근·설두중현의 정확한 저작 경위와 연도(1125년경), "벽암"이라는 이름의 정확한 유래, 제1칙(양 무제-달마 문답)의 정확한 원문과 "공덕이 없다"는 해석의 통용 정도, 대혜종고의 판목 소각 일화의 사실 여부.
- **[금강경]** 구마라집 한역의 정확한 연도(401년경), "금강"이라는 제목 비유의 정확한 출처, 혜능의 깨달음 일화(무경설법에서 들었다는 구절)의 정확한 서술.
- **[춘향전]** 암행어사 출두 시의 한시("금준미주는…")의 정확한 원문과 판본별 차이, 이본의 정확한 종수, 성립 시기.
- **[심청전]** 맹인잔치에서 모든 맹인이 눈을 뜬다는 결말의 판본별 유무, 성립 시기.
- **[성학집요]** 정확한 편찬 연도(1575년경), 5편 구성의 정확한 명칭·순서, 조선 후기 경연 교재로서의 실제 활용 정도.
- **[경세유표]** 정확한 저술 연도, "유표"라는 제목의 정확한 함의, 주례 참조의 구체적 방식.
- **[반계수록]** 정확한 저술 기간(20여 년 저술설), 이익·정약용으로 이어지는 계보 서술의 학계 통용 정도.
